=======================================================
PROJECT: TEXT-TO-COURSE (AI-Powered Learning Platform)
=======================================================

1. 📝 PROJECT DESCRIPTION & CONTEXT
-------------------------------------------------------
Text-To-Course is a full-stack, AI-powered educational platform designed to democratize learning by automatically generating comprehensive, structured courses based on any user-provided topic. 

When a user enters a topic (e.g., "Introduction to Machine Learning"), the platform orchestrates requests to Google's Gemini Generative AI (Gemini 2.5 Flash) to act as an expert curriculum designer. It first generates a high-level syllabus divided into modules and lessons. Then, it dynamically generates detailed content for each lesson. The generated lessons are rich and multimodal, supporting text paragraphs, code snippets, relevant YouTube video integration, and multiple-choice questions (MCQs) to test the user's knowledge.

The application features a modern, responsive frontend built with React and Tailwind CSS, and a robust backend built with Node.js, Express, and MongoDB. User authentication and authorization are securely handled via Auth0.


2. 🛠️ TECH STACK & TOOLS USED
-------------------------------------------------------
* Frontend: React 19, Vite, Tailwind CSS, React Router, React Markdown.
* Backend: Node.js, Express.js, Mongoose.
* Database: MongoDB (storing hierarchical data: Courses -> Modules -> Lessons).
* AI / LLM: Google Generative AI SDK (@google/generative-ai), Gemini 2.5 Flash.
* Authentication: Auth0 (OAuth2 with JWT bearer tokens).
* External APIs: YouTube Data API (fetching dynamic video content).


3. 🚀 RESUME POINTS (Current Implementation)
-------------------------------------------------------

4. 🔮 ADVANCED AI CAPABILITIES & FUTURE SCOPE 
   (What more can be done / Architectural Enhancements)
-------------------------------------------------------
The following features represent the cutting-edge of AI development and can be integrated into the platform to make it an enterprise-grade EdTech tool:

A. Retrieval-Augmented Generation (RAG) for Custom Syllabi
Allow users to upload their own textbooks, PDFs, or company documentation. By chunking this data and storing it in a Vector Database (like Pinecone or ChromaDB), the LLM can generate courses strictly based on the uploaded proprietary material, reducing hallucinations and enabling corporate training use-cases.

B. Adaptive Learning Engine
Instead of static MCQs, implement AI-driven knowledge tracing. When a user fails a quiz, the system sends the incorrect answers to an LLM to analyze the knowledge gap and dynamically generates a personalized "remedial lesson" before allowing the user to progress.

C. Context-Aware AI Tutors
Embed a conversational AI chatbot on every lesson page using LangChain. The chatbot is injected with the specific lesson's context (system prompt) to act as a specialized tutor, allowing users to ask follow-up questions or request further code explanations in real-time.

D. Agentic Workflows for Quality Assurance
Move away from single-prompt generation to a Multi-Agent system (e.g., using LangGraph or CrewAI). A "Curator Agent" writes the course, a "Reviewer Agent" fact-checks it against reliable web sources, and a "Formatting Agent" ensures perfect JSON schema compliance before saving to the database.

E. Multimodal Asset Generation
* AI Voiceovers: Integrate Text-To-Speech (TTS) models (like ElevenLabs or OpenAI TTS) to dynamically generate audio narration for the lesson text.
* AI Imagery: Use Image Generation models (Flux, DALL-E 3) to generate custom cover images for courses and explanatory diagrams within the lessons.
